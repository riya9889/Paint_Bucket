Put one reference image per paint bucket in this folder.

The FILE NAME is the exact product name that must appear on the bucket label:

    Bison Glow.jpg
    Silk Blend.png
    Royal Matt.jpeg

Underscores are converted to spaces (Silk_Blend.png -> "Silk Blend").
Supported formats: .jpg .jpeg .png .bmp .webp
Click the refresh button in the web page after adding files (no restart needed).
